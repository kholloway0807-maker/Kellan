# Kellan Project

## TikTok Viral Hooks Library

Installed at: `./tiktok-viral-hooks/`

A curated database of viral TikTok video breakdowns. Use this as a reference when writing hooks, scripts, or content strategies.

### Structure
- `_data/all-videos.json` — master list of all ~153 viral video entries (view counts, hook patterns, niches)
- `breakdowns/en/` — full per-video breakdowns with exact opening lines, retention moves, and copy-paste script templates
- `by-niche/en/` — breakdowns grouped by niche (Entertainment, Finance, Beauty, Food, Tech, Fitness, Other)
- `by-pattern/en/` — breakdowns grouped by hook pattern (Curiosity Gap, Challenge/Test, Unexpected Twist, etc.)

### How to use
- **Finding hooks by pattern**: `./tiktok-viral-hooks/by-pattern/en/hook-<pattern-name>.md`
- **Finding hooks by niche**: `./tiktok-viral-hooks/by-niche/en/<niche>.md`
- **Full breakdown for a video**: `./tiktok-viral-hooks/breakdowns/en/<year-month>/<slug>.md`
- **All videos data**: `./tiktok-viral-hooks/_data/all-videos.json`

### Top hook patterns available
Curiosity Gap, Challenge/Test, Unexpected Twist, Rhetorical Question, Challenge + Binary Choice, Social Proof + Curiosity Gap, Mystery/Curiosity Gap, and 140+ more.

### Niches covered
Other (74), Entertainment (50), Finance (9), Beauty (8), Food (7), Tech (3), Fitness (2)
